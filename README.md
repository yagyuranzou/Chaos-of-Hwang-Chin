# CHAOS of HWANG CHIN  // 黃巾之亂
**Generative Ritual Device: 4CH Synthesizer × Tarot Logic**

The **CHAOS of HWANG CHIN** is an interactive generative system that bridges a randomized card deck with a 4-channel synthesizer and  Tarot Interpretation output. By triggering the "Fate Activation" (**運勢発動**), the user converts the chaotic essence of the Yellow Turban Rebellion into modern electronic signals.

> *Note: This is also a boring mini card game.*

## 🎴 Card System // 運勢発動 (Deck Specs)
A deterministic randomization engine utilizing a **34-card deck** (32 Base Cards + 2 Legendary Jokers).  
* **Selection Logic**: Cards are **Randomly Drawn** from the deck. The system ensures no duplicate cards are drawn in a single session.

### Base Deck (32 Cards)
* **Suits**: ♠, ♥, ♣, ♦ (4 types)
* **Indices**: 0 - 7 (8 types)
* **Event Mapping**:
    * **0: Spy (細作)** — Signal Stabilization
    * **1: Fire Attack (火焼糧車)** — Noise/Saturation Event
    * **2: Headache (頭風)** — Oscillator Detuning
    * **3: Assassin (刺客)** — Impulse/Trigger Logic
    * **4: Performer (名伶)** — Melodic Progression
    * **5: Poison (中毒)** — Internal Instability
    * **6: Morale Boost (気勢如洪)** — Gain/Amplitude Max
    * **7: Incense (迷香)** — Filter/Resonance Blur

### Legendary Jokers (2 Cards)
* **The Peerless Warrior (国士無双)**: Unique fate; triggers extreme frequency shifts.
* **Heroic Legend (英雄伝説)**: Pulse of legend; triggers global random glitching.

## 🔮 Tarot Interpretation // タロット解釈
The ritualistic text output is not static. The **Tarot Interpretation** is dynamically generated based on the specific **combination of the selected General and the 4 drawn Cards**.

* **General Influence**: Sets the "Daily Advice" (**今日宜**).
* **Card Combination**: Each card contributes a unique line of "Fortune Prose" (**吉利話**) that alters based on the General's current state.

## 🎧 Audio Engine // 合成器 (4CH Synth)
Real-time generation of four distinct signal layers based on card input:
* **CH1 Rhythm**: Square Wave (Pulse / Noise)
* **CH2 Lead**: Sine Wave (Melody / Pitch)
* **CH3 Pad**: Triangle Wave (Atmosphere)
* **CH4 Bass**: Square Wave (Sub-harmonics)

## 🕹️ Operations // 操作方法
1. **Activate Fate (運勢発動)** Roll the dice for a General and draw 4 cards to generate the sonic and textual fate.
2. **Monitor Waveform (波形監視)** Visualize the 4-Channel Mix via the integrated green phosphor Oscilloscope.
3. **MIDI Output (MIDI出力)** Export the generated sequence as a MIDI file for further reconstruction in any DAW.
